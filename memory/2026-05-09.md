### Key Observations
- **`LOAD_FILE` works** — MySQL has file read access
- **Special characters break time-based blind** — non-printable bytes (`\xae`, etc.) cause sqlmap to retry with escalating delays until timeout
- **Nginx config reveals:** `server { listen 443 ssl;` → SSL on 443

### Why Boolean-Based Failed
- Boolean-based blind requires the app to return **different responses** for TRUE vs FALSE
- This app always returns `302 → register.php?e=invalid+invitation+code` regardless
- Therefore boolean-based is **impossible** on this target — time-based is the only viable blind technique

### Why Time-Based Chokes on Special Characters
- Time-based blind extracts data **one character at a time** via binary search
- When it hits a special/non-ASCII byte, the comparison logic breaks
- sqlmap retries with longer delays, eventually timing out
- **Fix:** Use `SUBSTRING()` + `LOCATE()` to extract only known-safe ASCII text (like `root` directive)
